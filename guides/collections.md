# Maps and sets · 16–18

A hash map associates keys with values; a hash set keeps distinct keys. Lookup
may return `None`, so decide how to handle a missing score or count. For
frequencies, read the previous count, add one, and store it again. The tests
also cover repeated entries.

See [MoonBit fundamentals](https://docs.moonbitlang.com/en/stable/language/fundamentals.html).
