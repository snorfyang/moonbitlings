# Arrays and callbacks · 11–12

Visit array elements in order. To build a mapped result, start with a fresh
array and push the result of calling the provided function on each element.
To count matches, keep a mutable counter and test each value. Check both an
empty array and a mixed array in the supplied tests.

See [MoonBit fundamentals](https://docs.moonbitlang.com/en/stable/language/fundamentals.html).
