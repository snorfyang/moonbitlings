# Generics and traits · 09–10

A type parameter lets one function work with several concrete types. A trait
bound states which operation the function needs; `Compare` enables comparison
in the maximum exercise. The next exercise implements the same behavior for
two types through a trait.

See [MoonBit fundamentals](https://docs.moonbitlang.com/en/stable/language/fundamentals.html)
and [methods and traits](https://docs.moonbitlang.com/en/stable/language/methods.html).
