# Getting started · 00

Each exercise has a small MoonBit module. The current source is in
`exercises/<id>/main.mbt`; make it compile or pass its tests. `watch` checks
changes on save, while `verify <id>` checks once. `hint <id>` gives a nudge.
The introduction already passes so you can practice moving to the next item.

For a language overview, see the [MoonBit tour](https://docs.moonbitlang.com/en/stable/tutorial/tour.html).
