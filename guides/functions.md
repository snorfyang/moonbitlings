# Expressions and functions · 01–04

MoonBit functions declare parameter and return types. The final expression of
a block is its value. A loop can update a `let mut` variable; a recursive
function needs a case that stops calling itself. In these exercises, first
read the return type and the tests, then change only the missing body.

See [MoonBit fundamentals](https://docs.moonbitlang.com/en/stable/language/fundamentals.html).
